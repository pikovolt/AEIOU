# 外部自動処理サンプル拡張

1つの DLL から複数の機能を提供できることを示す、外部 DLL discovery のサンプルです。

- **ランダム整数**: 選択範囲を指定範囲のランダム整数で埋めます。ステップ数 `1` ならすべてのフレーム、`2` なら1フレーム飛ばしで、選択された各列を処理します。
- **AEコピー（サンプル）**: 選択した1列を AE Keyframe Data 形式へ変換し、DLL自身がクリップボードへ書き込みます。セル値は整数または空欄とし、FPS、先頭フレーム、AEバージョン、秒への変換有無を実行時に指定します。これは外部DLLによるクリップボード操作が可能であることを示すサンプルであり、本体の除外行設定などは使用しません。

## ビルドと配置

1. `AEIOU.sln` をビルドします。
2. 対象構成の出力（例: `bin/x86/Release/AEIOU.Automation.Sample.Random.dll`）を、`AEIOU.exe` と同じ場所に作成した `Extensions` ディレクトリへコピーします。
3. AEIOU を再起動し、右クリックメニューの **拡張自動処理** からサンプル機能を選びます。
4. 各機能のパラメーターを入力して実行します。

`AEIOU.Automation.Abstractions.dll` は本体と同じ場所にあるものを利用するため、`Extensions` にはサンプル DLL だけを配置してください。拡張 DLL は本体と同じ権限で実行される信頼済みローカルコードとして扱われます。

この実装は `Form1` を参照せず、公開契約のスナップショットを使用します。ランダム整数は変更候補だけを返し、AEコピーはクリップボード操作のために `System.Windows.Forms` を直接参照します。独自の拡張を作る際は、公開された引数なしコンストラクターと一意な小文字 ASCII command ID を維持してください。
